# templates/ - образцы файлов для генерации

Qwen берёт файлы отсюда как образцы, когда создаёт конкретные файлы под проект пользователя.

## QWEN.md.tmpl

Шаблон для генерации корневого `QWEN.md` на шаге 9a AUTOPILOT. Содержит плейсхолдеры:
- `{{PROJECT_NAME}}` - имя проекта
- `{{PROJECT_ONE_LINER}}` - одно предложение о чём проект
- `{{STACK}}` - технический стек
- `{{LANGUAGE_RULE}}` - на каком языке Qwen общаться с пользователем

Qwen заполняет плейсхолдеры ответами из интервью и записывает в корень как `QWEN.md`.

## qwen-settings.json.example

Образец `.qwen/settings.json` после прохождения шагов 4 и 5 AUTOPILOT (hooks + 4 запрета безопасности).

**Это не валидный рабочий файл** (Qwen Code может ожидать свою версию формата). Образец даёт Qwen понимание структуры, в реальном файле Qwen использует актуальный формат Qwen Code.

Структура:
- `hooks.Stop` - звук при завершении задачи
- `hooks.Notification` - звук при запросе разрешения
- `permissions.deny` - запреты опасных команд

Кросс-платформенная команда звука использует `afplay` (Mac) с fallback на PowerShell `console.beep` (Windows) и терминальный bell `\a`.
