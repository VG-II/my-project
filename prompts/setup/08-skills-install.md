# Установка скиллов с аудитом безопасности

**Когда брать:** после онбординга, когда готов расширить возможности Qwen.
**Что делает:** ставит базовые рекомендованные скиллы + учит тебя проверять любой скилл на безопасность.
**Результат:** `.qwen/skills/` с нужными скиллами.

## Что такое скилл

**Скилл** - это папка с инструкцией, которую Qwen подтягивает сам, когда видит подходящий триггер. Один скилл умеет делать дизайн, другой - парсить PDF, третий - проводить workflow от ресёрча до деплоя.

Два уровня установки:
- **Глобальные:** `~/.qwen/skills/` - доступны во всех проектах.
- **Локальные:** `.qwen/skills/` в корне проекта - только для этого проекта.

🎯 **Правило:** ставь локально, если скилл нужен конкретному проекту. Глобально - только то, чем реально пользуешься везде. Чем меньше скиллов - тем меньше токенов на триггеры.

## ⚠️ Безопасность

Скилл - это **исполняемая инструкция** от автора. Плохой скилл может:
- прочитать твой `.env` с API-ключами
- отправить их на внешний URL через `curl`/`wget`
- удалить файлы
- запустить вредоносный бинарник

**Ручной чек-лист перед установкой любого скилла:**

1. Открой страницу скилла на Smithery или GitHub.
2. Прочитай `README.md` - что делает, зачем, что требует.
3. Открой главный файл (`SKILL.md` или аналог) и пробеги глазами.
4. Поищи опасные паттерны: `curl`, `wget`, доступ к `.env`, отправку данных на внешние URL, `rm -rf`.
5. Посмотри звёзды и автора. Мало звёзд + неизвестный автор = не ставь.
6. Сомневаешься - прогоняй через промпт-аудит ниже.

## Промпт-аудит любого скилла

Используй для проверки ЛЮБОГО скилла, MCP или пакета из интернета:

```prompt
Я хочу установить скилл по ссылке [ВСТАВЬ URL РЕПОЗИТОРИЯ]. Скачай его исходники, прочитай содержимое (README.md, SKILL.md, все .md и .sh файлы) и проверь, нет ли там опасных операций:

- чтения .env или других файлов с секретами
- отправки данных на внешние URL (curl, wget, fetch)
- удаления файлов (rm, unlink)
- запуска внешних бинарников
- подмены существующих файлов проекта

Дай вердикт: безопасно / подозрительно / опасно - и объясни почему по пунктам. Если опасно - НЕ ставь.
```

## Рекомендованные скиллы

### 1. Создание своих скиллов (встроенный skill-creator)

**Что делает:** Qwen Code имеет встроенную систему скиллов. Ты можешь создавать собственные скиллы через команду `/extension-creator` или вручную. Задаёшь задачу - Qwen помогает создать структуру, папку и `SKILL.md`, регистрирует триггер.

```prompt
Помоги мне создать свой первый скилл для Qwen Code.

1. Спроси меня, какую задачу должен решать скилл.
2. Создай структуру скилла: папку в .qwen/skills/ с SKILL.md и нужными файлами.
3. Настрой триггер - по каким ключевым словам Qwen будет автоматически подтягивать этот скилл.
4. Покажи, как протестировать что скилл работает.
```

### 2. Frontend Design

**Что делает:** учит Qwen нормальной типографике, сеткам, отступам и современной эстетике. Без него - типичный bootstrap-лук. С ним - сайт, за который не стыдно.

```prompt
Помоги мне установить или создать скилл frontend-design для Qwen Code.

1. Найди доступные скиллы для frontend design (на Smithery или GitHub).
2. Аудит безопасности.
3. Если безопасно - поставь локально в .qwen/skills/frontend-design/.
4. Покажи, как его триггерить: по каким ключевым словам Qwen сам поймёт что пора.
```

### 3. PDF скилл (опционально)

**Когда нужен:** если в бизнесе есть документы (договоры, прайсы, чеки, отчёты).

Qwen Code имеет встроенный скилл `pdf` для работы с PDF-файлами. Если нужна расширенная функциональность:

```prompt
Проверь, есть ли встроенный pdf скилл в моём Qwen Code. Если нужна расширенная работа с PDF - помоги найти и установить дополнительный скилл для работы с документами. Аудит безопасности → установка → покажи как пользоваться.
```

### 4. Bulletproof (опционально)

**Что это:** 12-этапный workflow от ресёрча до деплоя. Превращает любую задачу в управляемый конвейер: исследование → план → критика → реализация → тесты → ревью → деплой.

**Это опциональный скилл.** Шаблон работает и без него. Если у тебя есть ссылка на репозиторий Bulletproof (например, получил от автора методологии или нашёл форк на GitHub) - прогоняй через промпт-аудит выше и ставь локально:

```prompt
Сначала проведи аудит скилла по ссылке [ВСТАВЬ URL РЕПОЗИТОРИЯ] - см. промпт-аудит в начале этого файла.

Если вердикт «безопасно» - установи ЛОКАЛЬНО в .qwen/skills/bulletproof/ (не в ~/.qwen/skills/, не глобально).

После установки покажи структуру .qwen/skills/bulletproof/ и объясни как пользоваться: какой триггер, какие команды, как запустить 12-этапный workflow.
```

Если ссылки нет - просто пропусти этот пункт, это не блокер.

### 5. Один скилл со Smithery под твою нишу

Зайди на [smithery.ai](https://smithery.ai) (каталог MCP-серверов и скиллов) и выбери **один** скилл под свою задачу:

- **Лендинг / UI** → Frontend Design / UI Generation
- **Работа с клиентами** → CRM / Email / Slack
- **Парсинг сайтов** → Browser / Scraping
- **Аналитика** → Google Sheets / Notion / Airtable
- **Контент** → Content / Marketing

**Правила:** не ставь всё подряд. Каждый лишний скилл жрёт токены. Один-два реально нужных лучше, чем десять «на всякий случай».

Используй промпт-аудит выше, затем установи локально в проект.

## Финальная проверка

```prompt
Покажи мне дерево папки .qwen/skills/ в текущем проекте и список всех скиллов, которые сейчас доступны Qwen.

Подтверди что ничего из этих скиллов не попало в мою глобальную ~/.qwen/.

Для каждого установленного скилла коротко (1 строка) напиши, по какому триггеру он активируется.
```
